# Theoxenia

An open-source, evidence-first Python lab for reproducible searches of public radio technosignature data and near-Earth records.

This repository is being initialized for the Mission Control M0 implementation. No telescope observations, live worker, or deployed dashboard are present in this bootstrap commit.
