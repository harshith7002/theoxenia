# Security

Report a vulnerability in this repository through GitHub private security advisories for [mpetyx/theoxenia](https://github.com/mpetyx/theoxenia/security/advisories/new). That path stays off the public issue tracker.

Do not open a public issue, pull request, or discussion for a vulnerability. Do not include a secret, credential, token, or raw scan file in the report. Describe the version, the command, and the effect.

The maintainer account is [@mpetyx](https://github.com/mpetyx). There is no separate security mailbox in this repository.

This file does not ask for a release and does not publish a disclosure.
