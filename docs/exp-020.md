# EXP-020 Nimitz public-record baseline

`make fusion-baseline` runs:

```bash
xenia fusion baseline --lat 31.0 --lon -118.5 --start 2004-11-14T00:00Z --end 2004-11-15T00:00Z --radius-km 800
```

The command writes `runs/<RUN_ID>/baseline.json`, the response bodies `cneos.json` and `gfz.json`, and `manifest.json`. The pillar is `III · Fusion`. The experiment id is `EXP-020`.

## What the request measures

The CNEOS URL is the NASA/JPL Fireball API with `date-min` and `date-max` only. The latitude, longitude, and 800 km radius are stored in the manifest and are not sent. `count` is the API record count for that time window. It is not a count of records inside the radius. The recorded window body has `count` as the JSON string `"0"`.

The GFZ URL is `https://kp.gfz.de/app/json/` with `index=Kp` for the same UTC window. Kp is a planetary index. It is not a value at the coordinate. The recorded body has nine definitive samples from 2004-11-14T00:00:00Z through 2004-11-15T00:00:00Z. Their maximum is 4.0.

Space-Track is not queried. No account is created. Satellite passes are not computed.

## Transport

The client tries Python `urllib` with the default TLS context. If that attempt fails with `CERTIFICATE_VERIFY_FAILED`, it retries with `/usr/bin/curl` and the operating-system trust store. The curl command does not pass `-k` or `--insecure`. A different network error does not switch tools.

When the live attempt fails for this exact window, the command reads `tests/fixtures/fusion/cneos-window.json` or `tests/fixtures/fusion/gfz-kp-2004-11-14.json` only if the file's SHA-256 matches the response measured on 2026-10-12. Those hashes are `8c51803de9a1f0bec29fcb163212d69b7996fcfb2ab1b7b5a89df676d1e5fcce` (82 bytes, CNEOS, HTTP 200, Date `Mon, 12 Oct 2026 22:22:15 GMT`) and `22b8fb82c275247b70696a1150fe17f6561590bbe299a107592de4ea5b057276` (394 bytes, GFZ). A mismatch raises and writes no baseline. Another date does not reuse these files.

`demo` stays false for a live fetch and for that recorded response, because both are measured bytes. The manifest says which one this run used. A body that was not measured is not given a count.

## Page card

This branch does not contain the Mission Control renderer that lights the near-Earth card. That renderer is on the detail-pages branch. It reads a non-demo manifest whose `experiment_id` is `EXP-020` and whose parameters include integer `fireball_count` and numeric `kp_max`. After that branch is merged with this one, those parameters are what the card prints.

## Checks this command does not do

Re-entry catalogs, exercise notices, and balloon tracks are not fetched. ADS-B has no 2004 history in the project notes. Those omissions are not measured nulls.
